# Next.js + Supabase Auth

Este projeto inclui uma tela de autenticação funcional com cadastro e login usando o Supabase e estilizada com Tailwind CSS.

## Como rodar o projeto

1. Extraia o conteúdo deste arquivo ZIP.
2. Renomeie o arquivo `.env.local` e insira suas credenciais do painel do Supabase (`URL` e `ANON_KEY`).
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
